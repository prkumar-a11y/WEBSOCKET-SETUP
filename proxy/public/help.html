WebSocket Applications Help

Each application connects through the proxy on port 8000. Help buttons open this page so the live behavior and test actions are in one place.

Chat

Five simulated users join the room. They type and publish messages every three seconds.

  • Messages receive increasing sequence numbers.
  • Typing indicators show who is composing.
  • Receipts move from delivered to read.
  • Idle users receive new-message notifications.
/chat

E-Commerce Live Updates

Customers receive changes without refreshing the page.

  • Publish inventory changes.
  • Broadcast price drops.
  • Push order-status updates.
  • Use the event feed to see each update.
/ecommerce

Trading Dashboard

The dashboard streams a simulated market continuously.

  • BTC and ETH prices update every second.
  • Each market shows top-10 bid and ask levels.
  • Orders emit pending and filled notifications.
  • Portfolio balances change after trades.
  • Price alerts fire when thresholds are crossed.
/trading

Gold Necklace Auction

The auction starts at ₹50,000 when the first client connects.

  • Simulated users bid every two seconds.
  • The countdown runs for two minutes.
  • Concurrent bids receive ordered sequence numbers.
  • The highest valid bid wins.
  • A winner notification is sent at closing.
/bidding
